# Gurpreet Singh Kainth - Portfolio

A responsive personal portfolio website built as a web-development practice project using:

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Premium dark theme
- Responsive mobile layout
- Personal profile image
- Downloadable resume
- GitHub, LinkedIn, Instagram and LeetCode links
- Email contact link
- Skills section
- Education timeline
- Project showcase
- Typing animation
- Scroll reveal animations
- Mobile navigation
- Back-to-top button
- Demo contact form

## Run in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
